How it works

Cards are positioned with CSS custom properties (--x, --y, --r) for a scattered layout. The .stage captures mousemove and computes each card's distance via Math.hypot, mapped through gsap.utils.mapRange into a 0→1 proximity. At the radius edge the scale is 1 — no snap, just a smooth wave. Each card gets a single gsap.to() with overwrite: true.

Core Logic

const stage = document.querySelector(".stage"); const cards = gsap.utils.toArray(".card"); stage.addEventListener("mousemove", (e) => { cards.forEach((card) => { const r = card.getBoundingClientRect(); const d = Math.hypot( e.clientX - (r.left + r.width / 2), e.clientY - (r.top + r.height / 2) ); const p = gsap.utils.clamp(0, 1, gsap.utils.mapRange(0, radius, 1, 0, d) ); gsap.to(card, { scale: 1 + (maxScale - 1) * p, duration: dur, overwrite: true, ease: "power2.out" }); }); });
